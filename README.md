### 👨‍💻 Sobre mim

Sou desenvolvedor web fullstack e estudante de **Sistemas de Informação**, com foco na construção de aplicações escaláveis e bem estruturadas.

Tenho especial interesse em **arquitetura frontend**, componentização e organização de código.  
Não apenas faço interfaces — eu projeto sistemas pensados para manutenção, crescimento e legibilidade.

Minha abordagem prioriza:

- separação clara de responsabilidades
- clean code
- padronização de componentes
- previsibilidade de estado
- experiência do usuário consistente

Além do desenvolvimento, também estudo **filosofia da tecnologia e ética digital**, buscando compreender o impacto real dos sistemas que construímos.
